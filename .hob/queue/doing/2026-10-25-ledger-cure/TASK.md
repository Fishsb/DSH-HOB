# TASK（账本根治 · 第一批）：立三条件检，先只报不拦，产出全量存量清单

作业书只写三件。

## 一、要落实什么

在**既有**「正本形态」那一族内**新增**三组断言，⛔ **不新增 `check:` 命令**（避免动 `package.json`、正本收尾表与族数下界这三处联动）。
**第一批一律「只报不拦」**（与既有「报警模」同形：不计入退出码，但必须印出来）。

**① 现状类文件禁时间词**

- 词表（**可枚举、写进判据里**，注释写明这是"会随动作变假"的一类）：
  `目前` · `现在` · `当前` · `最新` · `尚未` · `已上线` · `已加载` · `未加载` · `未生效` · `至今` · `暂时` · `近期` · `已落地` · `已完成`
- **扫描面**：账本区根的**现行正本** + `volumes/**` 里的**卷正文**。
- **三类白名单，逐类写明理由并落到注释**：
  - **规则件**：那几份**本身就是规则/禁令/判据说明**的文件或段落（逐条**列名**，⛔ 不许用通配）——
    这类里面出现这些词是**在讲规则**，不是**在声称状态**；
  - **反引号内**：被反引号包住的片段（引用、名词、代码）不计；
  - **历史件**：`archive/**` 与 `volumes/*/rounds/**` **整片不扫**（历史就该保留原话）。
- ⚠ **⛔ 不许**用"某词出现几次"当判据，**要定位到文件 + 整句**，便于逐条处置。

**② 每份正本有字节预算**

- 上限**从预设行读**（⛔ 不硬编码，读完把值贴出来）；**逐份给预算**，⛔ 不许全库一个数。
- 超预算 ⇒ 报出来，并**给出该份最肥的三节**（逐节字节数），便于下一步拆卷。

**③ 指针必达**

- 正本里出现的 `volumes/**` · `archive/**` · `.hob/**` 路径**必须存在**；
- 正本里引用的 `§x.y` 式节标**必须能在同一份文件或其指明的卷里检索到**；
- ⚠ 判"指不到"的**必须同时贴两端原文**（引用处 + 检索范围），⛔ 不许只说"找不到"。

**④ 负向对拍（必须有，否则这批等于没做）**

三组各造一次：往一份**原本干净**的文件里塞一处违规 ⇒ 必须报出来且**点名是哪一处**；还原 ⇒ 复报零。
⚠ 还原用 `cp` 备份 + `cp` 还原 + **逐字节核回**；⛔ 不许用版本控制命令还原。

**⑤ 产出全量存量清单**

把①的**全部命中**整理成表：**文件 · 整句 · 哪个词 · 你的分类（状态字 / 规则 / 历史 / 判据说明）**。
⚠ 分类要**逐条给理由**；⚠ **⛔ 本单不许改任何一个字** —— 只出清单。

## 二、怎么验收

- 三组断言各自的**处数**（改动前 / 改动后）+ **同批抬该族登记下界**（只升不降，写明理由）；
- **负向对拍六段原文**（三组 × 造/还原），每段要能看到"点名是哪一处"；
- **存量清单全表**（命中总数 + 逐条四列）；
- **白名单逐条列名**（规则件那几类必须列到文件/段落，⛔ 不许写"等"）；
- 上限读数原文（预设行 + 值）；
- 报警模的证据：**三组报出的违规不影响退出码**（贴一次退出码）；
- `check:all` 退出码 + 汇总原文（⚠ 该族处数应只增不减，其余族不变）；
- `git status` 两仓全扫，单列本单引入的每一行；
- 一句话：**这一轮之后要不要重启**。

## 三、不许碰什么

- ⛔ **不许改账本正文任何一个字**（正本、`volumes/**`、`archive/**` 一律只读）—— 本单只立判据、只出清单。
- ⛔ **不新增 `check:` 命令**、⛔ 不改族数下界、⛔ 不动 `package.json` 的 scripts。
- ⛔ **不许为了让存量变少去放宽词表**、⛔ 不许把某份文件加进白名单来消灭命中
  （⚠ 白名单只准装"本身就是规则/历史"的，装"有问题的"一律算违规）。
- ⛔ 不动 `src/**`、`.hob/**`、别的项目、真实 profile、看板。
- ⛔ 不许用版本控制命令做还原。
- ⛔ **不重启**；⛔ **不提交任何仓**。
- 既有记录只读；✅ 只可新增 `archive/2026-10-25-ledger-cure/REPORT.md`。
