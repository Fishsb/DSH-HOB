### 2. 形态：装进 profile 的插件

```
宿主 profile（用户已有的，不新建 profile）
├── @deepseek-ai/dsh-base
├── @deepseek-ai/dsh-web-app        ← Web 界面
└── dsh-hob                          ← 本插件，就装在这里
```

**关键性质**：
- **不是独立实例**，不占独立 profile，不占端口
- 跟着宿主 profile 一起启动、一起关闭
- **一份源码、一次安装**（不需要多端部署、不需要产物同步）

**为什么这个形态成立**：桌面级悬浮窗需要真桌面宿主（WSLg 给不了透明/置顶/无边框）
—— 本插件**不需要悬浮窗**，因此不需要独立实例，也不需要跨 OS。

**运行环境**：宿主 profile 内的插件（本机部署取值：`web` profile / 端口 `3080`）。
