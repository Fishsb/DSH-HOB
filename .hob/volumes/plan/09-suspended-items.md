### 9. 挂起项与「保留不扩建」项

⚠ **两类别混**（混了就会把"已实现"读成"没做"、或把"暂缓"读成"已在用"）：

- **挂起（暂缓）** = **暂时不做、将来可捡回**；⚠ **不修、不改、不删**，也**不算垃圾、不许顺手清理**。
- **已实现 · 保留不扩建** = **代码在用、行为已在**；⚠ **只是本阶段不再加功能**，⛔ 不是"没实现"、更不是"挂起"。

## 9.1 挂起（暂缓）

| 项 | 为什么暂缓 | 载体在哪 |
|---|---|---|
| **跨系统通信（M6b）** | 属**另一个方向**（与别的系统对接，⛔ 不是"另一个 DSH 实例"）；⚠ 用户裁定**暂缓** | 设计在 §8 第 7 步；⚠ **无实现** |
| **Orb 适配** | 用户「暂时不需要适配挂载 orb」 | 代码在归档目录；Orb 侧配置与预设**保留不动** |
| **悬浮球 / 悬浮窗 / 产出面板** | 用户「抛开悬浮窗悬浮球的需求」 | 同上 |
| **Hob 端桌面启动方式** | 独立实例才有此需求；本方案无独立实例 | 无 |

## 9.2 已实现 · 保留不扩建（⛔ 不是挂起）

| 项 | 是什么 | 本阶段边界 |
|---|---|---|
| **同实例会话通信（M3）** | 列活会话 + 投递 + 建会话（强制工作区归属） | 保留；⚠ **投递 ≠ 执行** |
| **闭环派活与回执（M5）** | 投递 → 等对方跑完 → 回传 → 唤醒派活方；记「待投递」中间态 | 保留；⚠ **回传 ≠ 验收** |
| **并行隔离推进** | 借用宿主看板：建卡 · 隔离执行 · 只读回收 · 派会话合并 | 保留；⚠ Hob **仍不建卡、不合并** |
| **首次铺骨架 / 设置面 / 可读权限控制（三档）** | 均已实现并在用 | 保留；⚠ **三档仍只改"读到哪里"**，无写、无命令、无组队 |

⚠ **跨系统（M6b）是暂缓项**（见 9.1）—— 它与本表的**同实例**能力不是一回事，⛔ 不许合并成一句"通信都没做"。
⚠ 另有**一条已批准的需求**（**逐会话档位后端与创建弹窗**，REQ-04）：它既不是"挂起"，也不在本表 ——
⚠ 它的**加载与现状见 `CONTEXT.md` §2.1b**；⚠ **新建只开放最低档**（另两档呈现但不可选）。
⚠ **它未被标成"已完成"**：真机渲染 / 真实宿主归档 / 真机 dispose 均未验。差距逐条记在 `CONTEXT.md` §2.1b，需求口径见 `volumes/requirements/REQ-04.md`。
