### CHG-015 · 2026-10-07 · 「决策自主」条款 + 允许向用户提问；收尾必跑增列
- **触发原因**：用户就四项待办作出裁定。
- **用户原话（逐字）**：「1清理，2可以，但是尽量不要提问，根据项目方案主线进行决策推进就行了，除非只能由用户决策才可以推进的可以提问（直线hob预设，Hob-Execute禁止提问），3推理强度又没有绑定，用户爱怎么调节就怎么调节，4可以」
- **审查结论**：同意。「尽量不问 + 只在只有用户能定时才问」与现有分工一致，属**细化**（**不取代**职责划分）。
- **调整内容（**现行决策纪律**）**：
  1. **契约新增「决策自主」条款**：能按方案与账本主线判断的**自行决策推进**；**只在只有用户能定**（**产品方向 / 取舍 / 范围 / 代价接受度**）时才问；**判不出属于哪一类 ⇒ 就该自己定**；问的方式**优先在回复里摆选项与代价**，**不为能自己判断的事停下**
  2. **允许 Hob 使用交互提问**：声明面**指名增行** + 白名单增一名
  3. **新增两个脚本并挂进 `package.json`**：`exp:next-id`（只读输出下一可用编号，**必须宽正则** —— 窄正则会给出偏小的最大号并导致**撞号**，本仓已**两次踩坑**）· `check:experience`（编号唯一 / 连续 + 四要素齐备，自某编号起强制、更早**只提示不计失败**）
  4. **「收尾必跑」增列** `check:experience`
  5. **`reasoningEffort` 归用户所有**：**不绑定任何东西**，用户可自由调节 ⇒ **不纳入漂移跟踪**
- **状态**：**已生效**（**长期有效**）
- **关联**：UD-68
