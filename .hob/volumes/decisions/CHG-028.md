### CHG-028 · 2026-10-10 · 文档与机检一致性：对拍通过判据入骨架 + 断言 D / D′（正本具名引用必须存在）
- **触发原因**：Hob 在正本里写「各轮作业书（R21 系 / R22 系 / **R23 系**）」，而 **R23 系并不存在**
  —— **执行方实测发现并报回**（第 24 轮），Hob 认账并改正。⇒ 暴露一条**同族第三次**的失效形态：
  **写的是"我以为它叫什么"，而不是"我去看一眼它叫什么"**（前两次：**E-108** 凭记忆写字段名 · **E-109** 凭记忆报数字不带口径）。
- **审查结论**：同意。**处置方向**沿用本项目一贯口径：**能机器核的不要靠人记**（E-108③ 的推论）
  ⇒ 不只是改错字，而是**把这条判据做成机检**。
- **调整内容（**现行口径**）**：
  1. **对拍的「通过判据」写进骨架说明**（`.hob/README.md` §1.4）：
     > **负向对拍的通过判据 = 退出码非零（`exit ≠ 0`）** **且** **输出里有可读的断言行**。
     ⚠ **只判退出码不够** —— 实测踩过（**E-112**）：被检查对象的形状被改坏时，**检查脚本自己先崩**，
     同样 `exit 1`，但**一条可读的 ✗ 行都没有**（只剩堆栈）⇒ **分不清"抓到了违规"与"检查器崩了"**。
  2. **新增机检 断言 D / D′** ——**正本里的具名引用必须真的存在**：

     | 断言 | 扫什么 | 判据 |
     |---|---|---|
     | **D** | 正本里 `archive/<日期目录>/…` 形态的**具体路径** | 逐条 `existsSync`；不存在 ⇒ **FAIL + exit 1**，打印**哪份正本 / 哪一行 / 引用了什么** |
     | **D′** | 正本里 `TASK-R<数字>…\.md` 形态的**作业书文件名** | 按 **basename** 在 `archive/*/` 下比对；不存在 ⇒ **FAIL + exit 1** |

     ⚠ **实存条数随文本变化** ⇒ **以实测输出为准**（⛔ 不在此处写死数字）。
     ⚠ **已知代价（如实）**：**它也会咬住"描述某条不存在的引用"的正文** —— 与 **E-114** 同族。
     ⇒ **处置 = 描述这类缺陷时用"形状描述"，不写字面量**（见 CHG-030 的负向纪律）。
  3. **占位形态按字符集自然排除**（无需排除表）：`archive/<日期>-<名>/` 里的 `<` 与 CJK **不在** 正则字符集内
     ⇒ **散文里的词不会被当成引用** —— 满足"**防误报**"要求。
  4. **⚠ 零引用时不判 FAIL、也不静默**：打印「**无对象可查（已扫描，非跳过）**」。
     理由：**"没有可查对象" ≠ "通过"**，静默会让读者把"没输出"当成"查过了、没问题"。
  5. **用 `existsSync` 而非查 git**：正本引用的是**账本区里的事实文件**（可能尚未 `git add`）；
     "在不在 git 里"是**另一条判据**（断言 C 与 MUST-TRACK 已在管）。
  6. **新增经验 E-113**：**把"轮次号"当成了"文件编号"** —— 写引用前**先实测存在**；
     **区分"轮次号"（叙事）与"文件名"（具名物）**：**叙事里的号不必都有文件，但写成文件名就必须存在**
     （⛔ 别为了齐整给每轮都编一个 `TASK-Rnn.md` —— 那是**造假**，比缺引用更坏）。
- **⚠ 一条停手纪律（本轮实证有效）**：指令举例的 `TASK-R*.md` 形态**实测 0 处**
  ⇒ 执行方**没有硬造用例**，而是按指令**标题**改建**两支**（D 走路径、D′ 走作业书名）并**如实打印 0 处**。
  ⇒ 口径：**判据的"举例"与"标题"冲突时，以标题为准；对象为 0 时如实报告，不许造假对象**。
