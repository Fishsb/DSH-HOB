# CHG-074 · 落点定案：账本 = `<工作区>/.hob`；工具材料 = 插件自己的 `kit/`

## 一、决定（用户拍板 + 我补的落点）

| # | 东西 | 落点 | 谁的 |
|---|---|---|---|
| **1** | **账本**（正本 · 卷 · 归档 · 在途件 · 运行时 · 备份） | **`<工作区>/.hob/`** | 那个项目自己的，**进它自己的版本库** |
| **2** | **工具材料**（骨架说明 · 模板 · 角色方法论 · 契约 · 经验库） | **插件仓的 `kit/`**（⚠ 我定） | **插件自己的**，**一份** |
| **3** | 起一个新项目时往 `.hob/` 里放的东西 | **只有一个空账本**，⛔ 不带工具材料 | 那个项目 |

## 二、⚠ 为什么 `CHG-073` 的"⛔ 不许进 `.hob/`"现在作废

当时那条的理由是：**`.hob/` 是随包发出的骨架拷贝** ⇒ 账本进去会随包泄漏、骨架清单会从 39 件暴涨。

**用户这条决定把那个前提拆掉了**：骨架不再往工作区放 ⇒ `.hob/` 空出来。
⇒ **`.hob/` 从此只有一层含义 = 这个项目自己的账本。** 前提变了，结论跟着变。

## 三、`kit/` 为什么放这儿（我定的，给理由）

```
kit/
  README.md      这套材料是什么、谁读它
  INIT.md        新项目起手（⚠ 大幅缩小：只起账本，不铺工具）
  templates/     账本各件的起始形状
  roles/         角色方法论
  drafts/        契约（含 preset-contracts.md 那份镜子）
  experience/    经验库
```

| 为什么不是别的落点 | 理由 |
|---|---|
| ⛔ 放 `src/` | 这些是**运行时读的内容**、不是编译物；放进去会把编译面撑大，也容易被动过 |
| ⛔ 放 `preset/` | `preset/` 是**预设声明本身**，是有契约、有判据靶点的交付物，⛔ 不装杂项 |
| ⛔ 留 `.hob/` | **那正是账本的位置**（第一条决定的直接后果） |
| ✅ `kit/` | 名字即"工具包"，与 `src/` `scripts/` `preset/` 并列，⛔ 不与任何既有落点撞名 |

## 四、由此必须同批处理的五件（⚠ 少一件就出中间态）

| # | 事 | 关键点 |
|---|---|---|
| **1** | **`.gitignore` 要反过来** | 现在 `.hob/*` 是**整片忽略**的；账本进去之后它**必须被跟踪**。⚠ 只留窄例外（`runtime/` · `backups/` 这类生成物） |
| **2** | **骨架清单（39 件 `sha256`）** | 它的存在理由是"**拷贝 == 源**"—— 拷贝没了，这个理由消失。⚠ ⛔ **不许先删**：要等拷贝真的不再产生，否则就是"先拆闸后放车" |
| **3** | **`UD-118`（首次使用自动铺骨架）** | 范围从"铺 39 件工具材料"缩成"**起一个空账本**" |
| **4** | **`ledgerHome`** | 从**一个全局值**改成**按工作区派生**（`<ws>/.hob`）。⚠ 现在有一个硬编码兜底值，迁移后若配置被清空会**静默指回旧形态** |
| **5** | **发布物** | `kit/**` **必须在包里**（插件运行时读它）；⇒ `UD-129` 的**逐字节审查对象 = `kit/**` 全量**，⛔ 不再是工作区里的拷贝 |

## 五、⚠ 一处必须说清的取舍

`kit/**` 会**随包发给别人**，所以它里面 ⛔ **不许有**：本项目的账本路径、轮次号、`CHG`/`UD` 编号、本机绝对路径。

⚠ 这意味着 `kit/drafts/preset-contracts.md` 那份**人读版镜子**（现在与预设逐字一致、有判据盯着）
将来要么继续做镜子、要么改成"只留指针"—— 但那是**另一个决定**，⛔ 不夹带进本单。

## 六、不做的事

- ⛔ **不删**工作区里已有的 `.hob/`（⚠ 先盘清、先验，再谈移除）
- ⛔ **不并行**做两件事（搬 `kit` / 改账本落点）—— 本批已多次因并行互相覆盖
- ⛔ 不在本单改判据下界、⛔ 不提交、⛔ 不重启
