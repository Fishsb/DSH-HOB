### CHG-026 · 2026-10-10 · 账本区根目录只放"当前状态"：遗留过程产物一律归档
- **触发原因**：用户指令 —— **账本目录里所有账本文件都应当是最新状态**，**其他遗留的东西一律归档到 `archive/` 历史文档**。
- **用户原话（逐字）**：「整个账本目录所有账本文件都应该是最新的状态，其他遗留的东西都应该归档到archive历史文档」
- **审查结论**：同意。**这是 CHG-025 那条形态口径的补完** —— 该变更管的是"**文档正文怎么写**"，本条管的是"**账本区里该放哪些文件**"。
- **调整内容（**现行口径**）**：
  1. **账本区根目录只放正本**（`PROJECT.md` + 各本账本）**+ `archive/` / `backups/` / `runtime/`**（⚠ **直接列成员，不写数量**）
  2. **任何过程产物**（批次报告 / 阶段记录 / 快照 / 登记表）**一律进 `archive/<日期>-<名>/`，不进根目录**
     ⚠ **归档目录名有硬规则**：`YYYY-MM-DD-<slug>`；**写侧守卫**会拒不符者（见 CHG-030 的收紧）
  3. **本次收口**：遗留文件**逐份 `git mv`** 进归档目录（**版本历史随迁、零删除**）+ 该目录一份 `README.md`
  4. **引用点同步**：`.hob/README.md` 顶部说明 · §1 二分表 · §1.1 逐类判定表 · **§2 账本区目录树** · **§3 归档指针表** · §5 防漂移行
  5. **新增 §1.6 收口口径**（防复发，明文），并把「**账本区根目录只放正本 + 那几个目录**」写进 §5 防漂移行
  6. **作业书留档立为口径**：**每轮的 `TASK-*.md` 与 `TASK-*-ADDENDUM.md` 随该轮的账本仓提交入库**（放该轮 `archive/<日期>-<名>/`）——
     否则它们会长期悬在 `??` 里，且下轮的人（或 Hob）会**判不清来源**
- **⚠ 一条边界（如实）**：`.hob/EXPERIENCE.md` 与 `.hob/drafts/preset-contracts.md` 里另有若干指向早期文件的**旧路径引用**
  （**早在账本外置时就已失效，非搬迁造成**）—— **不逐条回改**（经验库纪律「**只追加、不重排**」；草案是**盘点快照**、不作维护）。
- **状态**：**已生效**
