### CHG-059 · 2026-10-17 · 「可读权限控制」三档改名（显示名 + 功能名；内部取值与字段名不变 · 限定句同批）

- **触发原因**：用户要求把设置里那组开关**改名**（原话见 `UD-133`）：功能名 `权限档位` → **可读权限控制**；
  三档显示名 `账本` / `项目` / `工作区` → **账本权限** / **文档权限** / **完全权限**。
- **审查结论**：同意（按 `UD-101` 三步走：先审落点 → 落方案本体 → 整份重构；落点见 `UD-133` 的原话与四条裁定）。
- **调整内容（现行口径）**：
  **① 功能名**：**可读权限控制**（中文）；英文面板用 `Readable-permission control`。
  **② 三档显示名**：**账本权限** / **文档权限** / **完全权限**（英文 `Ledger permission` / `Document permission` / `Full permission`）。
  ⚠ **三档「能读到哪里」一字未改**：账本权限 = 只读账本（+ 网络正文）；文档权限 = 另可读工作区 `.md`；
  完全权限 = 另可读工作区任意文件（含代码与图片）+ 列文件 + 跨文件搜索。
  **③ 机制一字未动**：内部取值仍 `ledger` / `project` / `workspace`；字段仍 `permission.level`；
  volatile 形状仍「父不标 + 子标」；白名单仍是三档单调（`ledger ⊂ project ⊂ workspace`）；
  单调执行哨兵、模块开关、`spawn.*`、`interconnect*` **全部不动**。
  **④ 「完全权限」必须带限定句**（`R-26`）：凡用户可见处出现该名，紧邻必须有
  「**完全权限 = 工作区里任何文件都可读，仍然不能写、不能执行命令、不能组队。**」
  —— 面板按三个位置落实（分段控件选项旁 · 选中后的「这一档的边界」行 · 页脚说明），**同源同句**，⛔ 不许三份各写各的措辞。
  **⑤ 记录类文本不追改**：轮次记录 · 既有 `CHG` / `UD` · `archive/**` · 经验库历史条目 **保留旧称**（`三档齐` 的第三档：记录类永久不改）。
- **不做（边界）**：⛔ 不改内部取值与字段名 · ⛔ 不改三档读的范围 · ⛔ 不加写 / 命令 / 组队 ·
  ⛔ 不动编排、看板、圆桌、`skill` / `present` · ⛔ 不给面板加新控件（除「这一档的边界」那一行）·
  ⛔ 不碰「无运行实体 / 空白会话」两处（用户尚未裁）。
