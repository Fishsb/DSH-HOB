### UD-01 · 2026-10-05 · 形态：装在 profile 内的插件
- **决策内容**：本插件**不做独立实例、不占独立 profile**，而是作为**插件装进用户已有的 profile**；并且**自带一个 Agent 预设**，该预设**基于 DSH 默认的极简模式**搭建。
- **用户原话**：「我需要这个项目是和 DSH 一样灵活扩展多模块插件的方式，他不用单独的一个 profile 是一个安装在 profile 内的插件，然后会和当前项目一样新建一个 Agent 预设，这个预设是基于 DSH 默认的极简模式去搭建」
- **影响**：废止"独立 profile / 跨 OS 双端"方向；不需要独立端口、多端部署、产物同步。
- **关联**：CHG-002
