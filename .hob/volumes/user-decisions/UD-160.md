# UD-160 · 账本目录定为 `.hob`；骨架模板改放插件自己那份，落点由 Hob 自决

**用户原话（逐字）**：

> 「账本目录还是定为.hob，骨架模版这些东西你自己看换个地方应该放项目那个地方，这些东西等于是项目本身的一部分，你自己看这些模版应该怎么放」

## 决定

| # | 项 | 决定 |
|---|---|---|
| **1** | **账本目录** | **`<工作区>/.hob`** —— 用户拍板，**取代 `CHG-073` 选定的 `ledger/`** |
| **2** | **骨架模板 / 角色方法论 / 契约 / 骨架说明** | **放插件自己那一份**（"项目本身的一部分" = 插件项目的源码资产）；**具体落点授权 Hob 自决** |
| **3** | **⛔ 不再每工作区一份** | 承接 `UD-159` |

## ⚠ 为什么这两条放在一起才成立

`CHG-073` 当时判"账本 ⛔ 不能进 `.hob/`"，理由是 **`.hob/` 是随包发出的骨架拷贝** ⇒ 账本进去会随包泄漏、且骨架清单会从 39 件暴涨。

⚠ **用户这条决定把那个前提拆掉了**：骨架拷贝既然不再往工作区放，`.hob/` 就空出来了。
⇒ **`.hob/` 从此只有一层含义：这个项目自己的账本。** 前提变了，结论跟着变，`CHG-073` 的落点作废。
