# UD-114 · 轮次登记改为「**一轮一文件**」—— ⛔ 不再往同一张表里逐行追加

**用户原话**（2026-10-15）：

> 这类像日志的表，不该每一次改动都往里加一行；应该像日志一样，每次改动留一个小的日志小文件，每次留下的就是一个文件，而不是反复往同一张表里追加。

**背景（Hob 据实说明，非用户原话）**：既有的「轮次与落点」表**一轮加一行**，而它住在一份**每轮被整份重写**、且**必须一次读完**（上限 64KB）的文件里 ⇒ **增长必然撞上限** ⇒ ⚠ **"裁掉几行"成为随时可用的动作** ⇒ ⚠ **同一缺陷已出三次**（**第 182 / 204 / 207 轮**各一次），⚠ **前三次修法均为"补回去 + 写成规矩"，三次都复发**。

**决定**：**轮次登记不再使用"同一张表逐行追加"这一载体** —— 改为**一轮一个小文件**：**每次留下的就是一个文件**。

**与既有口径的关系**：
- ⚠ **取代** **UD-108 / UD-111** 里"§5.1 表只留 N 轮 / 只移四行"的做法（⚠ 那个做法以"表还在、还能裁"为前提）；
- ⚠ 与 **UD-83**（账本只写当前状态）· **UD-95**（地图 + 分卷、一事一文件）· **UD-99**（每次改账本 = 一次整体重构）**同向**。

**状态**：active
