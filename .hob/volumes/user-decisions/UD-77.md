### UD-77 · 2026-10-08 · 推进会话总线投递
- **决策内容**：**推进同实例内投递**，**不借第三方插件**。由此**放开**旧有的半自动口径（"没有自动投递"这条禁令**失效**），并把契约里三处「There is NO automatic delivery」改写为「**投递 ≠ 执行**」。**两条硬约束**：① **目标会话由人指定**（**不自动挑**）；② **文件交接 `TASK.md` → `REPORT.md` 保留为降级路径**。
- **用户原话**：「那就方案B把，推进当前项目预定的M3 会话总线投递」
- **影响**：① 落地 = 会话总线模块由骨架改为实现（`hob_sessions` / `hob_send`）；② **口径**：投递只调 `agent.followup`(写一条消息进对方 inbox)，**不碰任何文件、不改任何共享状态**（不建卡 / 不移卡 / 不认领），**不代表活干了**；③ 这是本项目**第一次**让 Hob 能"指挥别的会话"，属**明确放开**，故契约与方案**同批改写**，不是悄悄放宽。
