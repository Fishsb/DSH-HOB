# UD-158 · 回复加第三种形态：**问答轮** —— 直接答，⛔ 不套四块

**用户原话（逐字）**：

> 「HOB预设是完全无法沟通，只有一个写死的回复格式吗」
> 「加第三种形态」

## 决定

现行只有两种形态（派活轮 = 实施指令 + 简要说明 · 其余轮 = 只出简要说明四小块）。
⇒ **新增第三种：问答轮。**

| 形态 | 何时用 | 长什么样 |
|---|---|---|
| **一 · 派活轮** | 本轮真的有活要交给实施会话 | `实施指令` + `简要说明`（现行不变） |
| **二 · 说明轮** | 本轮有进展 / 结论要交代，但没有活派出去 | 只出 `简要说明` 四小块（现行不变） |
| **三 · 问答轮（新）** | ⚠ **用户提问**、且本轮**没有**活要派 | ⛔ **不套四小块、⛔ 不出现「这轮做了什么」**。**第一句直接回答**；需要时后面补事实与依据。⚠ **只在答案本身没验过时**，末尾加一句"这条没验过" |

## 判别法（一句话，可机检到"有没有回答"）

**用户问句 → 第一句必须是答案。**
⛔ 但凡开头是"这轮做了什么 / 你说得对 / 我先说明" ⇒ **不是问答轮**。

## ⛔ 问答轮里明令不许出现

- ⛔ 「这轮做了什么」「现在什么状态」「要你决定的」「还没验证」四块**一律不出现**；
- ⛔ **自我复盘、自我检讨、把自己的行为当主题** —— ⚠ 这类内容**只进账本**，⛔ 不进回复；
- ⛔ 用一个新派活去回避问题（⚠ 本轮无活可派就别派）。

## 为什么（用户给的理由，照录）

> 「HOB预设是完全无法沟通，只有一个写死的回复格式吗」

⇒ 问题不在措辞，在**只有一种形态可用**：用户问一句，回复被迫塞进"这轮做了什么"那一格，
于是输出变成**关于我自己的汇报**，而不是**答案**。

## 边界

- ⛔ 不解除 `UD-134` / `UD-135`（`简要说明` 要写成人能懂的话）—— 那两条管**形态二**；
- ⛔ 不解除 `UD-141`（只有真派活才出代码块）；
- ⚠ **载体要同批改**：预设契约**人读版与机器读版必须同步**（⚠ 有一条机检盯两者逐字一致，⛔ 只改一版会红）。
