### UD-37 · 2026-10-05 · Windows 侧 profile 只保留 `desktop` 与 `web`
- **决策内容**：Windows 侧 profile **只保留 `desktop` 与 `web`**，其余全删；**方式：直接删除**（不归档改名）；**连 `hob` 一起删**。
- **用户原话**：「清理干净只保留desktop和web」+（三选一选定）「删 5 个，包括 hob」+（二选一选定）「直接删除」
- **影响**：⚠ **已知情代价**：PCL 启动器 Windows 侧按钮**持久失效**（profile 名写死在二进制里）。
