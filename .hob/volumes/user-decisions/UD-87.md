- **决策内容**：**保留"搬到 `~/.dsh`"这个方向**，但**搬迁方式改判**：先做"抽历史"再搬。
- **用户原话**：（本条系助手实测复核后的更正登记，无新增用户原话）
- **影响**：① 实测原判"账本区是独立 git 仓、`mv` 可保历史"**失实**（`.git` 在**父目录**、`dsh-hob/` 只是其子目录）⇒ **`mv` 方式作废**；② **正确方式**：**(a) 优先** 用 `git subtree split -P dsh-hob` 把子目录历史抽成独立分支 ⇒ 新址 `git init` 并接入该历史（**保住全部历史 + 新址是独立仓**）；**(b) 降级** 新址 `git init` + 首次提交全量快照，旧父仓保留原地作历史存档；③ 旧父仓保持不动（它还管着**另一个项目**的账本，本项目**不处置**）；④ **流程纪律**：任务书以后须明写「**前提核实不符 ⇒ 立即停手上报，不执行动作**」，并作为**独立停手点**。
