# 11 · 账本的写法口径（页头引注块）

> ⚠ ⚠ **本份的历次"改前整份"副本**（**R-17**）—— ⚠ **多份并存、互不改动**（「归档件只增不改」）：
> ⚠ **每一份归档目录的 `README.md` 里都写了"它对应哪一版" + 字节数 + md5 + sha256** ⇒ **要判"哪份对应哪版"，读那份清单**（⛔ 不在本页抄数字 —— 抄了就会过期）。
> ⚠ ⚠ **R-17 的实际形态**：多数是"重写之后才补"（**从已提交修订里 `git show` 取回同一批字节** ⇒ 逐字节同值）；
> **最近两份是"改前先落"**（由实施会话 `cp` + `cmp`，因 **Hob 无命令能力**）。
> ⇒ **判据**：本轮要改正本之前，**副本必须已经在盘上**（`cmp` 无输出）。
> ⚠ ⚠ **最近一份「改前先落」的副本**：`archive/2026-10-21-ledger-pre-rewrite/sources/`（四份正本逐字节；清单件在同目录 `README.md`，写明每份对应 `v2.8` + 字节数 + md5 + sha256）。
> ⚠ ⚠ **★ "区域外未变"这个验收命题要按下面这句读（第 320 轮实测改写）**：
> ⛔ **不许**问"是不是只改了一处" —— **正本重写时顺手折入同批收口是常态**；
> ✅ **要问的是"除本批折入的内容外，有没有别的性质变更"** —— 且**一律按节标题在各自文件里定位**，⛔ **不许按行号区间摘另一份**（新增行会让行号整体位移，会把"新增"误报成"整节都改了"）。

> ⚠ **形态口径（UD-88 / CHG-025）**：**改动即重构、旧的归档**；正文**不带历史说明**、**不堆批次摘要区**。
> ⚠ **快照口径**：**本文件里的一切计数 / 哈希 / HEAD / 字节数，都是「书写那一刻」的读数** ⇒ **要最新值一律命令实测**。
> ⚠ **措辞口径**：⚠ **凡"会随提交而变"的读数，一律写"在 X 时点实测为 Y"，⛔ 不写"最终值"**；⚠ ⚠ **且一律不许"推"——没跑过命令就不许写那个数**。
> ⚠ **状态字口径（CHG-030）**：**"还欠什么"只进 §2**；正本里出现的"状态"一律是**稳定判断**。
> ⚠ **版本口径**：**`PROJECT.md` 不带版本字面** ⇒ **要判"方案是哪一版"，看提交历史或 `CONTEXT.md`**。
> ⚠ ⚠ **编年体红线**：本文件**⛔ 不按编年体写**（不出现"## …（<日期> …）"这类时间戳章节标题）；历史一律进 `volumes/context/` 或 `archive/`。
> ⚠ **账本可读性（预算）**：**每份正本都应能被 `read_contracts` 一次读完** ⇒ **超限 ⇒ 默认路径给的是部分信息**；**收缩前必须先把当前整份归档**（**R-17**）。
> ⚠ **轮次号口径**：**"Hob 自己改正本的那一轮"与"验收它的那一轮"是两个号** —— 正本里只写**前者**；⚠ **编号会有跳号**（判据只要求**只增不减**）。
> ⚠ ⚠ **取号前先实测**：写记录件之前先 `ls volumes/context/rounds/` 看那个号有没有被占，⛔ **不许照抄作业书上的号**（按**实测最大号 +1**）。
> ⚠ ⚠ **"已入库" ≠ "盘上已提交"**：`git ls-files` 说"已入库" = `HEAD` 里有那个版本，而**盘上那份可能已是 ` M`** ⇒ **收口时必须 `git status` 全扫一遍**。
> ⚠ ⚠ **★ 可查的指认须先实测**：凡写"某轮立 / 某轮提交 / 已记在 §X" ⇒ **落笔前实测**；⚠ **本档位下 Hob 核不了 `.git`** ⇒ **凡要填号，一律在作业书里要求对方附实测原文**。
> ⚠ **正本由 Hob 在提交前写** ⇒ **账本仓随时可能有一笔待提交**（**结构性，非缺口**）。

> **⚠ 取最新值的命令（`<账本区>` = `/home/lk/.dsh/hob-ledgers/dsh-hob`）**：
> - 账本仓 HEAD：`git -C <账本区> log --oneline -1` · 工作区仓 HEAD：`git -C /home/lk/FF/dsh-hob log --oneline -1`

## 账本的职责边界

> **账本的职责边界**：每份账本只装一种寿命的真相；判别法是「这句话会不会因为这份文件之外的一个动作（一次构建 / 一次部署 / 一次重跑）而变假」—— 会 ⇒ 状态，只准进 `CONTEXT.md`；不会 ⇒ 才可能是事实或规则。
