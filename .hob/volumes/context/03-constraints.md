## 3. 关键约束速查（会咬人的那几条 —— 机制类；**纪律类见 §0.7**）

| 约束 | 内容 |
|---|---|
| **host 半边无热更新** | 改 `src/**`（含 `preset/**`）必须 `build` + **重载/重启**才生效；**client 半边按请求从磁盘读**，**刷新页面**即可 |
| **重启会归档旧执行会话** | ⚠ 投递给**已归档**会话会被**明确拒绝** ⇒ **重启后先确认目标会话仍是活的**；⚠ **新建会话在收到第一条消息前用户看不见** ⇒ **建完须立刻投递** |
| **⚠ 重启 / 重载会丢回执** | ⚠ **实测**：`running → idle` 是**事件**、不可轮询 ⇒ 重载前跑完的那条**永不再来** ⇒ **派完先核「在等回传」再离开**（§0.7） |
| **`lib/` 漂移不可见** | `lib/` 被 gitignore，宿主却加载它 ⇒ **改完 `src` 必须 build**（⚠ **复刻渲染前也必须先 build**，见 **E-140**） |
| **读上限：截断 ≠ 读不到** | ⚠ `read_contracts` **超上限即截断并标注**；但 **`read` 可带 `offset` 分块读完全文** |
| ⚠ **账本有自己的预算** | ⚠ **每份正本都应能被 `read_contracts` 一次读完**；⚠ **超限 ⇒ 默认路径给的是部分信息** ⇒ **收缩前先把当前整份归档**（**R-17**） |
| **"刷新行号"本身是陷阱** | 同批刷新用的是**改前**坐标 ⇒ **优先符号锚 / 文字锚** |
| **计数相等 ≠ 无事发生** | 多次实证 ⇒ **判据须"逐条 EXIT + 逐组计数并列 + 报构成"** |
| **同源判据会一起瞎** | 一个字符集写窄，**两面同时失效** ⇒ 已有**断言 K** 盯着字面量 |
| **归档是一个动作** | ⚠ **先落地旧版、再写引用**；且 **引用路径的形态要先过写工具那一关**（**按窄的那档取名**） |
| **归档只增不改** | ⚠ 写侧**拒绝对 `archive/**` 做 `overwrite`** ⇒ **要更正就追加更正段**，并写明"以本段为准"（**CHG-046**） |
| **"Hob 无命令" ≠ "插件不能读文件"** | **插件跑在宿主 Node 进程里，有 `fs` 能力** ⇒ **读数不必都靠跑命令**（**R-26**） |
| **执行方不在写账本那一侧时，账本区不可达** | ⛔ **"让执行方写账本"只在同实例成立** |
| **自引用读数是不可渲染的** | 文件含自己的字节数 / 哈希 ⇒ **原理上不可能** ⇒ **结构性拒绝**（⚠ **同族**：报告里不写"自身那一笔的号"，见 §0.7） |
| **渲染只能读账本区内** | 标记目标是**相对账本根**的路径 ⇒ **工作区里的事实无法渲染** |
| **机检抓不到"值过期"** | 断言 I 只抓**标记残留** ⇒ **值陈旧要命令实测** |
| **缩水守卫不可配** | `overwrite` **不足原文件一半即拒写** ⇒ 「**一次写到一半以上**」（⚠ **改前先归档**） |
| **单文件上限** | 读 / 写各有上限（⚠ **具体值以源码常量实测为准**）。⚠ **删改一处导致缩水超半 ⇒ 改成分两步写**（第 110 轮实测踩过） |
| **可选依赖必须反应式** | `ctx.get('svc')` **免 inject**，但 `ctx.svc.member` **不免** ⇒ 走 `ctx.inject([...], cb)` |
| **`ctx.inject` 返回 Fiber** | 不是函数 ⇒ 清理用 **`.dispose()`** |
| **别"构建期取一次"** | 别的 fiber 提供的服务 / 活状态，**每次现读** |
| **volatile 形状** | 父对象**不标** + **每个子字段各标**；模块侧**不许直读 `config.spawn.x`** |
| **机检零放宽** | 不许为通过而改断言语义；**新增断言必须负向对拍** |
| **对拍的通过判据** | ⚠ **不只"exit ≠ 0"** —— 还要**输出里有可读的断言行** |
| **判据要能容忍元讨论** | 判据**不能只按字符集形状匹配**；**对拍要覆盖"不该咬"的一侧** |
| **宽锚会假阳，窄锚才可用** | 扫整份文件会咬到"**如实记录的边界**" ⇒ **判据必须锚定形态**，**不许锚定词** |
| **一个常量只服务一条断言** | **扩范围前先搜该常量的全部消费点** |
| **写前先预演** | `write_hob` 先 `dryRun:true`；引用读数**以落盘返回值为准** |
| **脚本必须有落点** | ⚠ `scripts/*.mjs` 每个都要有 `package.json` 落点（**一层**，非递归）；反向也在；⚠ **且须进 `mustTrack`** |
| **`backups/` 是快照，不是已知良好态** | ⚠ **它忠实保存写坏的中间态**；**没有判据读它**（有意）；**不进 git**；⚠ **可作"上一稿"来源** |
| **报数字必须带口径** | 凡给数字**必带那条命令的原文**；⚠ **不要用"约 XX KB"** |
| **取退出码前先确认"外壳"没坏** | ⚠ **重定向失败**会被误当成**命令失败** ⇒ **先 `mkdir -p`**；**确认日志落盘数** |
| **引用编号 / 文件名前先实测** | **已多次**踩坑 ⇒ **写指令前先确认它引用的文件真的存在**（⚠ 第 110 轮擦边、**第 114 轮同批两中**） |
| **机械搬运要用会跑的尺子验收** | ⚠ 按**行号**切分会让**模块级声明"被吞进"函数体**；⛔ **不许用"退出码 0"代替逐行 diff** |
| **轮次号口径** | ⚠ **"Hob 自己改的那轮" ≠ "验收轮" ≠ "作业书编号"**（三者都是不同的号） |
| **查"是否已生效"** | ⚠ **不能只看产物戳** ⇒ **判据 = 行为读数**：**新代码独有字样是否出现** + **只有重启才会变的计数是否变化** |
| **并行隔离推进的五条机制事实** | ⚠ ① **执行预设缺省 = 部署默认**（**R-20**）；② **外部会话同步**会把本项目**每个会话**自动记一张卡（**R-21**）；③ 隔离目录 `.dsh-worktrees/` **未进忽略清单**（**R-22**）；④ **合并冲突** ⇒ **`--abort` + 停手上报**（**R-23**）；⑤ **隔离副本里账本面机检整族不可用**（**R-24**） |
| **⚠ 派单文案自查** | 一个主件里**两句话可能打架**（如"某区一个字节不许改"＋"填该区某文件第一行"）⇒ **模板已机器化防**（第 112 轮） |
| **⚠ 骨架里的路径也是引用** | ⚠ 机检**管不到** `.hob/**` ⇒ **改模板 / 骨架时同批核它引用的每一处路径**（第 114 轮同批两中） |
| **⚠ 报告必须由产生它的那一轮提交** | ⚠ 否则**自我延续**：下一轮又要提交它、又产一份自己的报告（第 115 轮立；判据 = **该轮收尾时账本仓 `status` 为空**） |
| **⚠ 报告不预写"自身那一笔"的号** | ⚠ **自指无解**：该号必晚于报告落盘 ⇒ **预写即 E-117 形态**（第 115 轮实测踩过一次）；⇒ 报告只写到**落盘那刻已存在**的读数（本轮同步进骨架） |
