## 一、§4 开工检查单（每轮照做）

1. **先读本文件** —— 拿现状、拿"还欠的活"。
2. **按需读 `PROJECT.md` 的对应节** —— ⚠ 用**针对性 `grep` / 带 offset 的 `read`** 取所需节。
3. **动手前扫 `.hob/EXPERIENCE.md` 对应主题**（⚠ **教训与机制细节的唯一来源**）。
4. **判断"该不该问用户"**：产品方向 / 取舍 / 范围 / 代价接受度 ⇒ **问**；**能按方案与账本判断的 ⇒ 自己定并推进**。
5. **派活前**：
   - **⚠ 先确认目标会话仍是活的**（`hob_sessions`；⚠ **建完立刻投递**）；
   - 指令**必须自带要点**（做什么 / 在哪 / 不许动什么）—— **路径只作补充**；写一句「**不要弹窗、不要停下等回答**」；
   - ⚠ ⚠ **卡内的"现状"与"应然"都要先跑一遍或先实测**（**R-25**）；**判据本身也要先在盘上跑一遍**（**第 150 轮立**）；
   - ⚠ ⚠ **凡写"盘上现状" ⇒ 须写明取自哪一刻 / 哪条命令**（**第 126 轮立**）；
   - ⚠ ⚠ **作业书第一行必须是 `claim:` 行**（**第 126 轮立**）；
   - ⚠ ⚠ **自查"我这两句话会不会打架"** —— ⚠ **§1 的明令与 §3 的允许清单尤其要对照**（**第 154 / 162 轮两次实测**）；
   - **引用的编号 / 数字 / 文件名先实测**；⚠ **"某断言会 FAIL"同样先核实**；
   - ⚠ ⚠ **填落点号 ⇒ 先 `git log --name-status` 实测"那一轮的产出落在哪一笔"**（**第 177 轮立**）；⚠ **每一行的号各自独立实测**（**第 179 轮收紧**）；
   - ⚠ **写"某轮立某条"⇒ 先在该轮提交里查一次**（**`E-154`**）；⚠ ⚠ **一切可查的指认（"已记在 §X 第 N 行"）同理**（**第 167 轮扩展**）；
   - ⚠ **写"某节是表 / 有几行"⇒ 先实测那一节的形态**（**第 171 轮立**）；
   - ⚠ ⚠ **写"永久 / 不再"⇒ 须给凭据**（**第 173 轮立**）；⚠ **写"顺延给下一轮"⇒ 先问"下一轮还会来吗"**（**`E-152`**）；
   - ⚠ ⚠ **要"移出 / 搬走"某一段 ⇒ 先确认没有判据硬编码指向它**（**第 179 轮实测 · 第 180 轮立**）；
   - ⚠ **写"下一轮才建的目标"一律用形状**（**`E-148`**）；
   - ⚠ **判据写成判据式，⛔ 不写死"预期数字"**；**⚠ 凡写读数须能指认出处**；⚠ **`N/M` 类计数 ⇒ 写明 `M` = 命令条数**（**`E-150`**）；
   - ⚠ **"同类项"的口径要写清** ⇒ **凡给清单，须同时给"家族口径"**（**第 147 轮实测**）；
   - ⚠ **新建目录 / 新成员 ⇒ 列全它该带的成员**（**第 150 轮立**）；
   - ⚠ **"只提交 + 收尾"类单 ⇒ 明写"落点回填顺延到 Hob 下一轮"**（**`E-152`**）；
   - ⚠ **登记表加行 ⇒ 第 3 列写明确值 + ⛔ 单元格里不写裸竖线**（**第 156 / 160 轮实测 · `E-155`**）；
   - ⚠ **⛔ 不在总结段里写"下一步会做 X"** ⇒ **一律进 §2.4 表**（**第 161 轮立**）；
   - **⚠ 自问五道**：① 禁令与要求冲不冲突？② 要加的行表里早有吗？③ 有没有把原本对的地方改坏？
     ④ "已改净"命令真跑过吗？⑤ 判据打在对的文件上了吗？；
   - **⚠ 若新立纪律 ⇒ 同批登记三处**（§0.7 · 经验库 · 骨架 §5.1）；
   - **⚠ 搬运 / 重构类 ⇒ 要求"先存基线、再动手"，并用逐行 diff 判"没弄坏"**；
   - **⚠ 整批移出内容 ⇒ 同批产出「移出行 → 槽位」逐行对照表**（**CHG-043**）；**⚠ 更正一处 ⇒ 与被更正处同批收口**（**CHG-046**）；
   - **⚠ 收缩 / 删改正本 ⇒ 先把当前整份归档（R-17），改完自查一遍，再派独立复核**；
   - **⚠ 重写正本后复算字节数**（**第 151 轮实测**：算过仍超）；
   - **⚠ 改一条口径时 ⇒ 扫全正本、扫全文件、扫全族 + 一次"含数词总扫"兜底**（**E-117 / E-118**）；
   - **⚠ 改一处措辞若它同时是某机检的扫描对象 ⇒ 同批重测「覆盖面读数」**（**第 121 轮立**）；
   - **⚠ 给机检加"收录判据" ⇒ 先问"谁被它排除在外"**（**第 122 轮立**）；
   - **⚠ 改判据 / 改骨架的轮 ⇒ 必须做「回归对拍」**（**第 148 轮立**）；**⚠ 新判据的判定行必须报"核了多少"**（**第 148 轮立**）；
   - **⚠ "超限 / 超标"类红修完 ⇒ 同批核"内容去哪了"**（**`E-151`**）；**⚠ 删引用类改动 ⇒ 逐处复读自足性**（**第 147 轮立**）；
   - **⚠ 判据要扫某个禁词 ⇒ 须点名"只在哪个格子里找"**（**第 124 轮立**）· ⛔ 不许用"通扫全文 = 0 命中"当判据；
   - **⚠ §0.6 与 §5.1 的收口在同一笔**（**第 124 轮立**）· ⛔ **不留 `⏳` 过轮界**；
   - **⚠ 要宣布"已加载 / 已生效 / 已改净" ⇒ 不能只靠自己**；**⚠ 新立检查 ⇒ 必须同时指定"谁负责让它变绿"**；
   - **⚠ 新增 / 改动预设 ⇒ 边界块（契书两份）+ 机检同批落**（**CHG-047**）；
   - **⚠ 改骨架 / 模板 ⇒ 同批核"换个工作区开箱得到的是新规矩还是旧规矩"**（**UD-103**）；
   - **⚠ §6 必须写明"报告由你自己提交"**（**第 115 轮立**）；**⚠ 报告类的派单 ⇒ 明确写"⛔ 不预写自身那一笔的号"**；
   - **写明"本次提交范围"**（模板 §7）。
6. **⛔ 写完交接文件 ≠ 派出去了** —— **投递才算**；⚠ **投递后当场读一次 `hob_orch_status`，核「在等回传」是否为 1**。
   ⚠ **可用 `write_hob(dispatchTo=…)` 一步完成"写 + 投"**。
7. **收工前跑收尾命令**（⚠ **先 `mkdir -p` 输出目录**、**确认日志落盘数 = 命令数**）。
8. **⚠ 收尾全绿 → 才提交**（**CHG-045**）；⚠ ⚠ **若红因"正本自身原因"而修法全在被禁改处 ⇒ 无解** ⇒ **如实报 + 写明"红灯已入库"**。
