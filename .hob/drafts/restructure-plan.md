## 0. 一句话方案

**Hob 保持"电话"（对用户）不变；Hob-Execute 从"执行者"升级为"项目组"——
不是给它加工具（它已有 103 个），而是给它一份能组织这些工具的契约；

## 3. 决定一：Hob-Execute 契约升级（编制表 + 阶段门禁 + 发布纪律）

**方式**：在现有 `prefix: |-` 里**追加三个章节**，**不动**既有六段（回报结构、禁弹窗、
交回规则）——那几处被 ⑤c / ⑤e 机检钉住。

### 3.1 新增 `## Your crew`（编制表）

声明它是一支**项目组**，并给出角色簇（仅**声明**，不新增工具）：

| 角色 | 职责 | 用什么工具 |
|---|---|---|
| **需求澄清** | 把用户意图厘清到可执行 | 与 Hob 来回（经用户转达） |
| **方案设计** | 出技术方案、评估可行性 | `read`/`glob`/`grep` + roundtable（可选） |
| **实现** | 真动手改代码 | `write`/`edit`/`bash` |
| **独立验证** | **不得自查**，验证要用读数 | `bash` + 重跑 + 字节比对 |
| **发布** | 灰度/验证/回滚 | `bash` + 平台能力 |
| **子代理调度** | 并行开工、按角色招人 | `spawn_teammate`/`team_task_*`/`wait_agent` |

⚠ **关键条款（对齐你之前的"禁止自产自审"纪律）**：**做了改动的角色不得担任该改动的验证角色**，
验证必须由另一成员（`spawn_teammate` 招独立成员）或另一轮完成。

### 3.2 新增 `## The path`（六阶段 + 门禁）

| 阶段 | 产出物 | 门禁（判据） |
|---|---|---|
| **1 定需求** | 可执行的需求 + 验收标准 | 验收标准**可测试**（写不出来 = 没想清） |
| **2 出方案** | 技术方案 + 影响面 | 方案含：改什么 / 不动什么 / 怎么验 |
| **3 实现** | 代码改动 + 自测 | 自测通过 + **提测门禁**（主流程冒烟） |
| **4 验证** | 验证报告（读数） | **独立于实现者**；P0/P1 全闭环 |
| **5 发布** | 发布计划 + 回滚预案 | 三板斧：**可灰度 / 可验证 / 可回滚** |
| **6 交接** | `REPORT.md`（六段） | 六段齐备；待决问题逐条可答 |

> 依据（第一轮 SDLC 调研）：缺陷修复成本 设计 1x → 实现 6x → 测试 15x → 上线 **100x**；
> Google SRE 发布协调清单；DORA「小批量 + 可靠测试」。

### 3.3 新增 `## Ship discipline`（发布纪律）

- **可灰度**：新版本先小流量
- **可验证**：技术指标 + **一个真实业务流程**（技术正常 ≠ 业务正常）
- **可回滚**：回滚**比发布快**，且演练过

## 4. 决定二：角色簇的三层载体（按可移植性分层）

⚠ **这是你"外部工具换环境就没有"那条约束的直接落点。**

| 层 | 载体 | 依赖 | 缺外部插件时 |
|---|---|---|---|
| **基础层**（必须有） | 角色簇写进 **Hob-Execute 契约** + `.hob/templates/ROLES.md` | **零外部依赖** | ✅ 照常工作 |
| **增强层**（DSH 原生） | Agent Teams：`spawn_teammate` / `team_task_*` / `wait_agent` | **DSH 原生**（`dsh-experimental-agent-team`） | ✅ 照常工作 |
| **可选层**（有则用） | roundtable 26 个 / free-search 5 个 / taskboard 3 个 | **外部插件** | ⚠ **必须降级**，见下 |

**降级路径（写进契约，使其可移植）**：

| 缺什么 | 降级做法 |
|---|---|
| 缺 **roundtable** | 用 `spawn_teammate` 招独立成员做评审（Agent Teams 是 DSH 原生，一定在） |
| 缺 **taskboard** | 用 `team_task_*`（DSH 原生）当任务板 |
| 缺 **free-search** | 用原生 `web_fetch`（Hob 侧）/ 直接给 URL |

⚠ **Hob 侧同理**：Hob 白名单里那 4 个只读查询（`taskboard_list`/`get`/`comments` + `roundtable_status`）
**全部来自外部插件** ⇒ 契约里须写明"没有它们时不查、如实说不具备"。
