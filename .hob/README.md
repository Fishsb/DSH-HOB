## 1. 骨架 vs 运行数据

`.hob/` 的内容按**文件性质**二分：

| 类别 | 判定标准 | 进 git？ | 位置 |

> **为什么这样切**：`.gitignore` **按路径匹配、读不到文件内容**，
> 所以「首行标记」在 git 上不可行；把运行数据下沉到子目录则要改目录结构定义。

**⚠ 清单必须逐项列全，不许靠推断**（2026-10-05 修订，见 `EXPERIENCE.md` **E-70**）：
`.gitignore` 的 `!` 例外**少列一项** ⇒ 该文件**静默不入库**，git **不报任何错**。
⇒ 本表的「位置」栏就是 `.gitignore` 例外的**唯一权威清单**；
改一处必须同步另一处，并由 `npm run check:gitignore` 机检（见 §1.4）。

### 1.4 机检：`npm run check:gitignore`

`scripts/check-gitignore.mjs` 把「**排除漂移**」从**静默**变成**显式 FAIL**：
它按 §1 的两栏清单逐条断言 `git check-ignore` 的结果，**违反任一条 ⇒ exit 1**。
改 `.gitignore` 或改本表后**都应跑一次**。
（⚠ 它用 `git check-ignore`（**纯规则匹配**）做断言 ⇒ 能区分
"**被规则排除**"与"**不存在所以没出现**" —— 后者**不**算通过，见脚本内注释。）

⚠ **同一脚本还带文档形态三条机检**（2026-10-10 起）—— 别以为它只管排除：
**A** 模板 ↔ 正本节名一致（覆盖**有模板的三本**）· **B** 正本无补丁式历史说明
（覆盖**四份正本**，含 `PROJECT.md`）· **C** 账本仓忽略规则不许写宽（见 §1.5）。
⚠ A / B 两个清单的**基准不同**（A 需模板、B 只需正本）⇒ 各用各的常量，**不可合并**
（合并会在扩一条时连坐另一条，见 `EXPERIENCE.md` **E-110**）。
⚠ 另带 **D / D′**（2026-10-10 · 第 25 轮，**判据于第 27 轮收紧**）—— **正本里"具名"的路径引用必须真的存在**：
**D** 扫 `archive/<YYYY-MM-DD-slug>/…` 形态的具体路径（**与写侧 `src/server/hob-write.ts` 的
`ARCHIVE_DIR_RE` 同源** —— 归档目录名必须是 `YYYY-MM-DD-<slug>`）· **D′** 扫 `TASK-R<数字>…md`
作业书文件名（按 basename 在 archive 的各日期子目录下比对）。
⚠ **按设计不计**（这些**不是**具名引用，**不许**把它们判成"不存在的引用"）：
占位形态 `archive/<日期>-<名>/` · `archive/<YYYY-MM-DD-slug>/TASK.md` ·
**示意名 `TASK-Rnn.md`**（编号非数字）· 通配 `TASK-*.md` / `TASK-R*.md`。
⚠ 引用 0 处时**打印"无对象可查"**（**不判 FAIL，也不静默**）。见 `EXPERIENCE.md` **E-113**（判据来源）
与 **E-114**（**判据必须容忍"描述它自己的文本"** —— 第 26 轮那次假阳性正是栽在这里）。

### 负向对拍：**通过判据不只是退出码**

> **负向对拍的通过判据 = 退出码非零（`exit ≠ 0`）** **且** **输出里有可读的断言行**。

⚠ **只判退出码不够** —— 实测踩过（`EXPERIENCE.md` **E-112**）：被检查对象的形状被改坏时，
**检查脚本自己先崩**（如对 `undefined` 裸访问 `.length`），同样 `exit 1`，
但输出里**一条可读的 ✗ 行都没有**（只剩一段堆栈）⇒
**分不清"抓到了违规"与"检查器崩了"**，看日志的人还得反推"它本来想查什么"。
⇒ 判据必须**两条都看**：先看**有没有失败**（退出码），再看**失败长什么样**（有没有指名的断言行）；
新增/修改断言后，除了正向跑，**还要拿"被检查对象的坏形状"喂一次**（否则那条路径永远跑不到）。

⚠ ⛔ **不许在该规则里写宽规则**（`*` / `**` 之类会**连带排掉四份文档与 `archive/`**）——

判据用 **git 自己的答案**（`git check-ignore --no-index`），**不解析 `.gitignore` 文本**。
⚠ 账本区读不到时该断言**明确打印"未执行"**，**不静默 PASS**。
